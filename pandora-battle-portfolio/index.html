04 · Engineering Highlights

Problem → System

기능 개수보다 설계 의도와 문제 해결 과정이 드러나는 영역입니다.

01 / NETWORK COMBAT

네트워크에서도 자연스러운 전투 흐름

서버 권한과 클라이언트 반응성을 함께 고려해 Ability 실행, Projectile, Hit 처리와 상태 변화를 구성했습니다.

02 / DATA DRIVEN

기능 추가가 쉬운 데이터 중심 설계

매치 규칙, 스킬, 무기 정보를 코드에 고정하지 않고 Data Asset과 컴포넌트로 분리해 반복 작업 비용을 줄였습니다.

03 / PRODUCT FLOW

게임플레이에서 Steam 배포 준비까지

전투뿐 아니라 로비, 세션, AI, 트레이닝, UI와 플랫폼 기능을 하나의 프로젝트로 완성했습니다.
