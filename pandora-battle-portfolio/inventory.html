해결하려던 문제

인벤토리 목록, 선택한 장비와 화면 표시를 한곳에서 관리하면 복제 수신 도중 중간 상태를 표시하거나, UI 코드가 아이템의 실제 소유 상태를 직접 변경하기 쉽습니다.

데이터에서 화면으로

  1. Item Definition공통 아이템 설정
  2. Instance / EntryID·수량·강화 등 소유 상태
  3. Change Notification완성된 변경 결과 전달
  4. Widget / ViewModel목록·선택 상태·HUD 표현

정의 데이터와 개별 아이템 상태

ItemDefinition은 공통 설정을, ItemInstance는 ItemId와 수량·강화 레벨 등 개별 상태를 표현합니다. 복제 엔트리를 통해 수신한 상태로 로컬 목록을 구성하고 아이템 타입에 따른 필터를 갱신합니다.

일괄 변경 이후 UI 알림

InventoryUpdateDepth와 변경 대기 플래그를 사용해 분리·병합·일괄 지급 중 알림을 보류합니다. 변경이 정리된 뒤 OnInventoryChanged를 전달하며, 삭제된 아이템을 참조하는 소비 아이템 퀵슬롯도 정리합니다.

속성 변경과 HUD의 연결

HealthBarViewModel은 ASC의 체력·레벨·경험치 속성 변경 Delegate를 구독합니다. 초기화 시 현재 데이터를 읽고, 해제 시 구독과 상태를 정리하여 UI가 소스의 생명주기와 함께 갱신되도록 구성했습니다.

설계의 결과

아이템 소유 상태와 표시 로직을 구분하고, 복제와 일괄 변경이 끝난 시점에 UI가 상태를 반영하도록 했습니다.
