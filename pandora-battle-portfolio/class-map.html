관계도 범위와 읽는 방법

저장소에 있는 C++ 클래스·구조체 정의를 분석한 정적 관계도입니다. 전방 선언, 열거형, 엔진 내부 타입, 자동 생성 코드 및 Blueprint 에셋의 연결은 노드에 포함하지 않습니다. 조건부 컴파일 분기는 함께 분석합니다.

상속은 파생 타입 → 부모 타입, 멤버 타입은 필드에서 사용하는 타입, 함수·별칭 타입은 선언된 반환값·인자·타입 별칭의 참조입니다. 소유권이나 실제 런타임 호출을 뜻하지 않으며, 같은 타입 사이에 여러 종류의 선이 있을 수 있습니다. 선택 주변에서는 현재 필터·연결 방향·관계 종류에 해당하는 직접 연결만 표시합니다. 전체 관계도는 양방향을 모두 포함합니다.

블록은 분석한 커밋의 헤더 선언 줄로 연결됩니다. 헤더가 없는 구현 전용 타입은 CPP로 표시하고 실제 .cpp 선언 줄로 연결합니다. AdvancedSessions 및 AdvancedSteamSessions는 외부 플러그인으로 구분했습니다.
