선정 기준과 읽는 방법

100개 핵심 클래스 중 선택한 클래스와 밀접한 관계를 한 화면에 보여줍니다. 한 구조도 안에서 공유 대상은 하나의 블록으로 표시합니다. 블록을 누르면 해당 클래스의 구조도로 이동합니다. ‘내용’은 하단 설명을, ‘GitHub’는 실제 헤더를 엽니다.

블록의 행은 실제 선언 필드이며 들여쓴 행은 구조체 안의 데이터입니다. 선의 화살표는 소유자·참조자·호출자에서 대상으로 향합니다. 선 위에 포인터를 놓으면 해당 관계가 강조되고, 누르면 근거와 설명이 하단에 열립니다. 같은 클래스의 상속받은 모든 필드나 모든 구현 보조 타입까지 표시하지는 않습니다.

Data Asset은 공유 설정, 인스턴스·컴포넌트는 실행 중 상태, SaveGame은 영구 기록입니다. 헤더의 초기값은 C++ 기본값이며 실제 에셋 콘텐츠 값과 다를 수 있습니다.
