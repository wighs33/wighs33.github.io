핵심 클래스 100

구조 이해를 위한 읽기 우선순위입니다. 설정·실행 상태·영구 저장·표시 데이터를 구분했습니다.

  1. #001 APdPlayerState ↗플레이어 상태의 중심

    플레이어의 능력·소유 목록·성장 컴포넌트를 묶습니다. 체력 수치나 스킬 설정을 이 클래스의 필드에 직접 중복 저장하지 않습니다.

    이 클래스 구조도 →
  2. #002 UPandoraComponent ↗소유 판도라와 장착 슬롯

    정의 기반 보유 목록·현재 선택·방향별 로드아웃·부여 능력 핸들을 관리합니다. 성장 레벨과 남은 포인트는 Tree에서 읽습니다.

    이 클래스 구조도 →
  3. #003 UPandoraDefinition ↗판도라가 무엇인지 정의

    표시 정보·무기 조건·성장 비용·선행 조건과 Skills 배열을 담습니다. 슬롯은 USkillDefinition을 직접 참조하며 외부에서는 Getter로 읽습니다.

    이 클래스 구조도 →
  4. #004 USkillDefinition ↗스킬 설정과 액션 트리

    비용·시간·피해·상태 이상·연출과 실행할 Action 템플릿을 보관합니다. 모든 판도라 스킬은 USkillAbility가 이 트리를 복제해 실행합니다.

    이 클래스 구조도 →
  5. #005 UPandoraTreeComponent ↗판도라별 성장과 포인트

    어떤 판도라를 몇 단계까지 성장시켰는지와 남은 포인트를 관리합니다. Definition의 비용·선행 조건을 검사한 뒤 성장 상태를 갱신합니다.

    이 클래스 구조도 →
  6. #006 UPandoraSkillSource ↗판도라 스킬의 출처 식별

    AbilitySpec.SourceObject에 연결됩니다. 정의와 슬롯 인덱스로 스킬을 조회하고, 이 SourceObject가 붙은 ASC의 활성 쿨다운 효과를 조회합니다.

    이 클래스 구조도 →
  7. #007 FPandoraSkillBinder ↗판도라 설정을 능력으로 부여

    서버에서 해금된 슬롯마다 공통 USkillAbility의 Spec과 SkillSource를 만들어 ASC에 부여합니다. 기존 능력을 재사용하고 입력 태그를 갱신하며, 멤버 저장 필드는 없습니다.

    이 클래스 구조도 →
  8. #008 UPdAbilitySystemComponent ↗능력·효과 실행과 속성 적용

    속성 초기화·변경·리셋을 직접 수행하고 입력은 관리자에 위임합니다. 출처 복제 지연 시 활성화를 보류하고, 종료·취소 시 대기 상태를 정리합니다.

    이 클래스 구조도 →
  9. #009 UBasicAttributeSet ↗전투 수치와 보정 계산

  10. #010 UPdGameplayAbility ↗게임 능력 공통 실행

  11. #011 USkillAbility ↗스킬 액션 트리 실행기

    이 클래스 구조도 →
